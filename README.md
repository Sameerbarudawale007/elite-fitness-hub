# 💪 Elite Fitness Hub

Elite Fitness Hub is a full-stack MERN (MongoDB, Express, React, Node.js) web application designed to manage gym members efficiently. From adding new members to tracking their status (active, expired, inactive), this project aims to simplify gym operations with an intuitive user interface.

## 🚀 Live Demo
🔗 [Project Deployed on Render](https://elite-fitness-hub-frontend.onrender.com/)  


## 🚀 Features

- 🔐 Admin Login & Authentication
- ➕ Add New Gym Members
- 📅 Track Membership Status:
  - Active
  - Expiring in 3 Days
  - Expiring in 4–7 Days
  - Expired
  - Inactive
- 🔄 Update & Delete Member Records
- 📊 Dashboard Overview
- 📁 MongoDB Database Integration

## 🛠️ Tech Stack

- **Frontend**: React, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Others**: Mongoose, Axios, Dotenv
